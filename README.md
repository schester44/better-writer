# Better Writer

A Raycast extension that improves text using Claude AI.

## Features

- Reads text from your clipboard
- Sends it to Claude to make it clearer and more professional
- Automatically copies the improved text back to clipboard
- Attempts to paste the improved text directly (works in Slack and other apps)

## Setup

1. Get an Anthropic API key from [console.anthropic.com](https://console.anthropic.com)
2. Open Raycast preferences and add your API key in the Better Writer extension settings

## Usage

1. Copy or select text you want to improve
2. Open Raycast and run "Better Text"
3. The improved text will be copied to your clipboard and pasted automatically

## Tips

- In Slack: Select text, run the command, and it will replace your selection
- Works best with short to medium-length text (messages, emails, comments)
